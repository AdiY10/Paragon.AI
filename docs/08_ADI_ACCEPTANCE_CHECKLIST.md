# 08 · Adi's Acceptance Checklist (plain language)

Use this on the deployed app. It takes about 20 minutes. Tick each item; anything that fails goes back to Amit with a screenshot.

## Getting in
- [ ] I received the app link and sign-in instructions privately (not in GitHub).
- [ ] I can sign in on my laptop **and** my phone.
- [ ] In a private browser window that is not signed in, the link shows only a sign-in page and no Paragon data.

## This Week (home page)
- [ ] It opens on a weekly summary that says how many items need attention, or clearly says "No material changes."
- [ ] Each item names the property, says what changed and why it matters, and shows the date or period of the data.
- [ ] Clicking an item shows the proof: the numbers, the source name, a working link to the source, and when it was last checked.
- [ ] Nothing on the page looks made up. Every number can be traced to a source.

## Portfolio
- [ ] I see a map and a list of Paragon's properties (36 imported from the public website, marked "unconfirmed" until confirmed).
- [ ] I can confirm a property, edit its name, and archive one.
- [ ] I can filter by state and see the map and list change together.
- [ ] Properties needing attention stand out, and it's clear why.

## A property page (try Kingston Marketplace and Cypress Lake Shopping Center)
- [ ] The map shows the pin, the rings (e.g. 1, 3 and 5 miles) and nearby businesses.
- [ ] Population and income for each ring appear with a "±" or a reliability label and the data period (e.g. "ACS 2020–2024").
- [ ] For Norwalk (Staples Plaza, 444 Westport Ave), the 3-mile population is roughly 84,000 and the 1-mile population roughly 11,500.
- [ ] Local jobs and unemployment are shown for the right county. For Connecticut properties this is a "Planning Region."
- [ ] Traffic shows a road name, a daily count and a year. For Kingston: Ulster Ave (US 9W), about 22,500 (2024) or newer.
- [ ] Cypress Lake shows it is in a FEMA flood zone (AE) and says this is a screening, not an official determination.
- [ ] I can drag the pin and the numbers update.
- [ ] Each section shows when its data was last updated. Anything missing says why ("not available," "not disclosed") instead of showing 0 or a blank.
- [ ] Nowhere does it claim to know the property's own vacancy, rent or value.

## Tenants
- [ ] I can see and edit a property's tenant list, and mark anchors.
- [ ] For Southside Shopping Center, the Rite Aid tenant shows its past bankruptcy filing with a link to the SEC filing and asks me to confirm the tenant is still there.

## Screening a new deal
- [ ] I type an address that is not in the portfolio and get a full profile within about a minute (basic numbers sooner).
- [ ] It shows "Strengths" and "Concerns" compared with Paragon's own properties (e.g. "higher than 78% of your properties"), each with proof.
- [ ] I can save it as a candidate.

## Comparing
- [ ] I can compare 2–4 locations side by side with a "portfolio median" column.
- [ ] Only meaningful "better/worse" differences are highlighted, and each number opens its proof.

## Trust and data
- [ ] The Data Sources page lists every source, what period it covers, when it was last checked, and whether it is OK, Stale or Failing.
- [ ] If something is stale or failing, the affected pages say so.

## Handoff materials
- [ ] There is a short testing guide, a list of known limitations, and a delivery report with the monthly running cost.
- [ ] Nothing in GitHub contains passwords or keys.
